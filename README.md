# AI Chatbot

A simple AI chatbot built using Python, Streamlit, Ollama, and Llama 3.2 1B.

## 🚀 Project Overview

This project is a locally running AI chatbot that allows users to interact with a Large Language Model through a simple Streamlit web interface.

The project is being developed step by step to understand how chatbot applications and local AI models work.

## 🛠️ Technologies Used

- Python
- Streamlit
- Ollama
- Llama 3.2 1B
- Git & GitHub

## ✨ Features

- Interactive chatbot interface
- Chat history
- Real AI-generated responses
- Local AI processing using Ollama
- No OpenAI API key required
